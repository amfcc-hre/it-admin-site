# AMFCC IT Administration

Protected system-control site for the IT Administrator.

## Upload

Upload every file in this folder to the root of the IT Administration GitHub Pages repository. Keep the filenames and folder level unchanged.

## First login

1. Open the site and use the current School Administrator PIN.
2. Enter your name in the audit field.
3. Change the **IT Administrator** PIN immediately.
4. Set the first **Library Staff** PIN.
5. Confirm the intended School Term or Holiday base mode.
6. Turn the Conference overlay on only when required. It works alongside the selected base mode.

The login page is fully removed after a successful PIN entry, and changing sections does not force the browser back to the top.

The browser files contain only the Supabase publishable key. PIN verification, permissions, and settings changes run in the database.
